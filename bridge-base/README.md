# Minecraft Ring bridge sources

This directory contains the Windows adaptation of the Elden Ring portion of
[minecraft-crossover-bridge](https://github.com/justbustin/minecraft-crossover-bridge)
by justbustin. The original MIT notice is preserved in [LICENSE](LICENSE).

The project targets Elden Ring App Ver. 1.17.1 (`eldenring.exe` 2.7.1.0) and
Minecraft Java Edition 1.21.1 on Windows x64. The maintained bridge is under
[elden-ring/](elden-ring/README.md).

Start with the [project README](../README.md),
[Windows setup guide](../docs/installation.md) and
[development guide](../docs/development.md). Build and launch from the repository
root using its Windows scripts. Other upstream game modules and macOS launcher
scripts are outside this repository's supported workflow.
