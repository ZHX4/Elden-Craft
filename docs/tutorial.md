# Quick-start video

[Watch or download the chaptered 1080p tutorial](https://github.com/ZHX4/Elden-Craft/releases/download/v0.3.0-tlauncher-preview.1/Elden-Craft-Quick-Start-Tutorial.mp4)
from the Elden-Craft preview release.

The four-minute video covers the release download, launcher setup, starting
Elden Ring and Minecraft, and a short gameplay demonstration. The video has
embedded chapter markers for supported players.

The tutorial shows an experimental build. Native bridge launch is limited to
Elden Ring App Ver. 1.17.1 / executable build 2.7.1.0 and Minecraft Java 1.21.1
with Fabric Loader 0.19.5. TLauncher remains optional and experimental; the
complete bridge connection and F8 handoff have not yet been verified
end-to-end. Offline single-player only.
